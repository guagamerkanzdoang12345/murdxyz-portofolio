Prepare your upload

Prepare your video for TikTok-ready 1080p quality.

MurdXyz Upload Method

Welcome!

Choose a target profile before uploading a video.

HEVC H.265 is OFF by default. If this browser's FFmpeg build does not have libx265, or HEVC encoding fails for a non-memory reason, Injection automatically falls back to H.264 Stable. A temporary progress pause around ~30% is not treated as an automatic failure.
SDR 8-bit is the safe default — TikTok's pipeline is built around SDR, so this avoids color washing. HDR 10-bit is only worth it if your source is actually HDR-graded; if this browser's encoder can't do 10-bit, it automatically falls back to SDR 8-bit.
Frame rate is locked to a fixed CFR value (no variable frame rate ambiguity for TikTok's parser). 120 FPS conforms the source up to 120 via frame duplication — it locks the rate, but doesn't add real motion smoothness (that's what AI Interpolation in Normal mode is for).
Injection mode re-encodes at a quality-targeted (CRF) profile, preserving your source's native aspect ratio (16:9, 9:16, 1:1, 4:5, 5:4, etc.) with no padding or stretching. TikTok can still recompress the file on its servers.
Reverse plays the video backwards. The clip is CFR-conformed before reversing to avoid stutter, and audio is discarded (video-only output). Because reversing needs every frame held in memory at once, longer/higher-resolution clips have an automatic duration limit — you'll get a warning before processing if your clip is too long for this to run safely in the browser.
2× Light AI
Experimental lightweight frame-smoothing mode. When ON, additional frames are created with temporal blending to make motion feel smoother. This is not a true neural-network AI model and does not guarantee avoiding TikTok compression.
AI Interpolation + Motion Blur
AI-style frame interpolation + directional temporal blur. This mode is optimized to stay lightweight in the browser: it is not a neural-network AI/optical-flow engine like RSMB Pro or Flowframes, but instead mimics smooth motion and motion-blur visually without removing the existing Upload Method features.
AI Interpolation FPS
Free: 60/120 FPS • Premium: 240/480/820 FPS ✦ Future Try: 3/3
60/120 FPS are available for Free. 240/480/820 FPS include a 3-use Future Try allowance. After the third high-FPS use, the allowance enters a 24-hour cooldown and resets automatically. High-FPS output is demanding for the browser and codec; 240/480/820 modes are experimental.
